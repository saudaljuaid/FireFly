# Security Policy

## Report a vulnerability

Please [report vulnerabilities privately through GitHub](https://github.com/saudaljuaid/Scarlite/security/advisories/new). Do not include exploit details in a public issue. Include the affected commit or version, a minimal reproduction, and the possible impact.

Reports for the latest `main` branch are welcome. Maintainers will review reports and coordinate any public disclosure through a GitHub security advisory.
