# Pinned Phos rendering fixtures

The eight HTML scenarios (`cards`, `nested`, `mixed`, `text`, `images`,
`malformed`, `clip`, and `start_page`) plus `local-link.html` are checked by
`tests/render_fixtures.rs`. `two-pixels.png` is a self-authored 2×1 RGBA
PNG with one red and one blue pixel. `local.css` tests linked local CSS.

`start_page.html` retains the owner-provided historical canary adapted from
[`research/phos-home/home.html`](https://github.com/saudaljuaid/Scarlite-UI/blob/6773b544e29b56e4bc938d04e84fe8f3e87450bc/research/phos-home/home.html)
in Scarlite-UI at commit `6773b544e29b56e4bc938d04e84fe8f3e87450bc`
(same project owner). Its only historical change is a
responsive `width:100%; max-width:630px` grid in this engine fixture. The UI
repository and its expected `home.svg` were not modified. The upstream UI
repository declares no license at that pin; no upstream open-source license
is inferred. The established owner-provided canary is retained under this
repository's distribution, without copying new UI content. Other historical
rendering fixtures are original project fixtures; no WPT CSS expectations
were copied or edited.

The fixture tests assert exact computed values, box widths and positions,
line fragmentation, image aspect ratios, SVG XML structure, redirect metadata,
template inertness, and repeated bounds. Cards and the start-page canary run
at 320, 640, and 900 CSS pixels.

The text and positioning milestone adds twelve original HTML fixtures:
`unicode`, `bidi`, `inline_geometry`, `relative`, `absolute`, `stacking`,
`position_clip`, `article`, `nav_cards`, `many_spans`, `long_token`, and
`malformed_deep`. These files are authored for Phos and distributed under
the repository's Apache-2.0 license. They contain no copied upstream CSS
expected output, screenshot, or downloaded page content. The two stress
seeds are expanded by the integration tests to exercise thousands of spans
and a long uninterrupted token; the malformed seed also has generated
boundary tests for nesting and repeated invalid declarations.

The complete source inventory is 28 HTML files, four PNGs, one CSS file, and
this source note. Visual SVG and PNG review artifacts are produced outside
the repository. The original parser corpora in `tests/upstream` and
`tests/fixtures` remain unchanged.


The intrinsic sizing, Flexbox, Grid, and responsive milestone adds six original
HTML sources under the same Apache-2.0 license:

| Source | Purpose and deliberate difficulty |
| --- | --- |
| `layout-navigation.html` | Growing/shrinking groups, baseline alignment, wrapping long labels, auto margin, padded positioned badge, 600px direction change |
| `layout-documentation.html` | Fixed sidebar and constrained flexible main track, nested controls, NBSP/combining/CJK/RTL text, 640px stacking, rounded overflow clip |
| `layout-dashboard.html` | Mixed track sizes, explicit two-column/two-row spans, implicit rows, nested flexible groups, 700px and 420px track changes |
| `layout-gallery.html` | Three intrinsic image ratios, HTML dimensions overridden by CSS, captions of unequal lengths, 650px/400px column changes |
| `layout-pricing.html` | Equal flexible columns with unequal content, column auto margins, mixed type sizes, 650px stacking, gradient and shadow |
| `layout-landing.html` | Nested Grid/Flex composition, intrinsic image with positioned annotation, RTL content, 700px stacking, gradient and shadow |

`tests/modern_fixtures.rs` runs all six sources at 320, 640, and 900 CSS pixels,
asserting computed breakpoint changes, item/track geometry, image aspect ratios,
overlay containing blocks, clip structure, unique SVG IDs, finite scene extents,
and output budgets. Algorithm-specific integration suites supply additional
freeze, span, intrinsic, anonymous-item, and hostile-input cases. Expected SVGs
and browser screenshots are review artifacts outside the repository, not the
only test oracle.

The new `layout-landscape.png` (96×64), `layout-portrait.png` (64×96), and
`layout-wide.png` (128×64) are small original raster diagrams generated by
`python3 tools/generate_layout_images.py`. The script uses only Python's standard
library and creates the pixels directly; there are no downloaded images,
unlicensed screenshots, external font files, or adapted upstream fixtures.
No new dependency was introduced for these sources or responsive CSS.

Source browser comparisons use the engine's bundled DejaVu Sans regular/bold
and Phos CJK faces loaded through `@font-face`, with a font-family override only.
An initial authoring error in four new sources combined `border-style:solid`
with only one edge width; browser CSS assigned medium widths to the other
edges. Browser inspection demonstrated those unwanted outlines. The sources
now explicitly set all four edge widths, preserving the intended separators.
That correction did not change the existing canary, any upstream expectation,
or conceal a layout failure. The gallery retains its CSS `height:auto` override
of HTML dimensions; the renderer defect it exposed has a geometry regression
assertion instead of a source workaround.


The original `effects.html` source adds six fixed-position paint cases for
premultiplied-alpha gradients, diagonal gradient geometry, out-of-range stops,
Gaussian shadow blur/spread, multiple-shadow ordering, transparent boxes,
borders, and overflow clips. Its raster comparison complements the structural
assertions in `tests/effects.rs`; detailed syntax and limits are documented in
[EFFECTS.md](../../docs/EFFECTS.md).

The historical invalid-width declaration assertion now uses `calc(10px + red)`
instead of `calc(10px)`, since the latter is intentionally supported by the new
typed calculation parser. It still verifies rejection and later-declaration
recovery; no upstream parser expectation changed.
